# Single-Family Housing Loan Analysis

A data engineering project analyzing Freddie Mac's public Single-Family
Loan-Level Dataset — modeling loan performance over time using slowly
changing dimensions, and surfacing delinquency/risk trends by geography
and origination vintage.

## Status
Work in progress.

## Data Source
Freddie Mac Single-Family Loan-Level Dataset (via Clarity Data Intelligence).
Raw data is not included in this repository per Freddie Mac's usage terms —
see https://capitalmarkets.freddiemac.com/clarity to access the dataset directly.
